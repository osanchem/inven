# 시약장 관리 앱 — 학교 설치 안내

> **소요 시간**: 약 10분  
> **필요한 것**: Google 계정 (학교 Google Workspace 계정 가능)

---

## 전체 흐름 한눈에 보기

```
[내 Google Drive]
   ↓ 1단계: 구글 스프레드시트 새 파일 만들기
   ↓ 2단계: Apps Script 백엔드 코드 붙여넣기
   ↓ 3단계: 웹 앱으로 배포 → URL 복사
   ↓ 4단계: 시약장 관리 앱에서 URL 입력 → 연결 완료
```

시트(스프레드시트)가 데이터베이스 역할을 합니다.  
데이터는 **선생님의 Google Drive에만** 저장되며, 개발자는 열람할 수 없습니다.

---

## 1단계 — Google 스프레드시트 새 파일 만들기

1. 브라우저에서 **[sheets.new](https://sheets.new)** 를 엽니다.  
   (Google 계정으로 자동 로그인됩니다)
2. 새 스프레드시트가 열리면 파일 이름을 자유롭게 바꿔 주세요.  
   예: `과학실 시약 관리` 또는 `○○고 시약장`

> 시트(탭)를 직접 만들 필요 없습니다. 앱이 처음 연결될 때 자동으로 생성합니다.

---

## 2단계 — Apps Script 백엔드 코드 넣기

1. 스프레드시트 상단 메뉴에서 **확장 프로그램 → Apps Script** 를 클릭합니다.

   ![메뉴 경로](확장 프로그램 → Apps Script)

2. Apps Script 편집 화면이 새 탭으로 열립니다.  
   편집기 안에 기존 내용(`function myFunction() {...}`)이 있으면 **전부 지웁니다**.

3. 이 패키지에 포함된 `apps-script/gsheets-backend.gs` 파일을 메모장으로 열어 **내용을 전체 선택(Ctrl+A) → 복사(Ctrl+C)** 합니다.

4. Apps Script 편집기에 붙여넣기(Ctrl+V) 합니다.

5. **저장 아이콘(💾)** 을 클릭하거나 **Ctrl+S** 를 누릅니다.

---

## 3단계 — 웹 앱으로 배포하기

1. Apps Script 편집기 오른쪽 위 **배포** 버튼을 클릭합니다.
2. **새 배포** 를 선택합니다.
3. 유형 선택 화면에서 ⚙️ 아이콘을 클릭하고 **웹 앱** 을 선택합니다.
4. 아래 설정으로 맞춥니다.

   | 항목 | 선택값 |
   |---|---|
   | 설명 | (비워두어도 됩니다) |
   | 다음 사용자로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |

5. **배포** 버튼을 클릭합니다.

6. **권한 승인 요청** 화면이 나옵니다.  
   - **액세스 승인** 클릭  
   - Google 계정 선택  
   - **'안전하지 않음' 경고**가 나오면: 왼쪽 아래 **고급** 클릭 → **○○(안전하지 않음)으로 이동** 클릭  
   - **허용** 클릭

7. 배포가 완료되면 **웹 앱 URL** 이 표시됩니다.  
   `https://script.google.com/macros/s/XXXXXXXX/exec` 형식의 주소입니다.  
   이 주소를 **복사** 해 두세요.

> ⚠️ 나중에 코드를 수정했을 때는 **새 배포** 대신 **배포 관리 → 수정** 을 해야 변경 사항이 반영됩니다.

---

## 4단계 — 시약장 관리 앱에서 연결하기

### 방법 A: 제공된 웹 앱 URL 사용 (추천)
배포해 주신 선생님으로부터 **시약장 관리 앱 주소(URL)** 를 받으세요.  
브라우저에서 그 주소를 열면 연결 설정 화면이 나옵니다.

### 방법 B: 직접 호스팅 (Netlify — 무료, 가입 없이 가능)
이 패키지의 `web/` 폴더를 직접 배포할 수 있습니다.

1. [app.netlify.com/drop](https://app.netlify.com/drop) 을 브라우저에서 엽니다.
2. 이 패키지의 **`web` 폴더** 를 그 페이지로 **드래그해서 놓습니다**.
3. 잠시 기다리면 `https://random-name.netlify.app` 형태의 주소가 나옵니다.  
   이 주소가 선생님 학교의 시약장 관리 앱 주소입니다.

### 앱에서 URL 입력
시약장 관리 앱 주소를 열면 아래 화면이 나옵니다.

```
[ Apps Script 웹 앱 URL 입력란 ]  [연결]
```

3단계에서 복사한 URL을 붙여넣고 **연결** 버튼을 클릭합니다.  
연결에 성공하면 재고 관리 화면으로 이동합니다.

---

## 여러 컴퓨터에서 함께 사용하기

- 같은 Apps Script URL을 각 컴퓨터의 앱에서 입력하면 동일한 데이터를 공유할 수 있습니다.
- 데이터는 30초마다 자동으로 새로고침됩니다.
- Google 스프레드시트를 직접 열어 데이터를 편집해도 앱에 반영됩니다.

## 문제 해결 (FAQ)

**Q. 연결 버튼을 눌렀는데 "연결에 실패했습니다"가 나와요.**  
→ Apps Script 배포 설정에서 **액세스 권한을 '모든 사용자'** 로 설정했는지 확인하세요.  
→ URL이 `/exec` 로 끝나는지 확인하세요. (`/dev`로 끝나는 주소는 테스트용으로 사용 불가)

**Q. Apps Script에서 '이 앱은 Google에서 확인하지 않은 앱입니다'라는 경고가 나와요.**  
→ 정상입니다. **고급 → 이동(안전하지 않음)** 을 클릭하면 됩니다.  
   이 코드는 선생님 본인이 만든 것이기 때문에 안전합니다.

**Q. 스프레드시트에 시트(탭)가 자동으로 생겼는데 괜찮나요?**  
→ 정상입니다. 첫 연결 시 `chemicals`, `logs`, `experiments`, `experiment_chemicals` 탭이 자동 생성됩니다.

**Q. 앱을 다른 학교에 전달하려면 어떻게 하나요?**  
→ 배포된 웹 앱 URL(Netlify 또는 제공된 URL)과 이 안내문을 전달하시면 됩니다.  
   각 학교는 본인의 Google 계정으로 1~3단계를 반복하면 됩니다.

**Q. 이전 학교에서 쓰던 데이터를 가져오고 싶어요.**  
→ 앱의 **재고현황 → CSV 가져오기** 기능으로 기존 데이터를 불러올 수 있습니다.
